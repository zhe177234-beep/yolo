# YOLO Studio 界面设计

页面在 MagicPath 插件中建立可编辑的 React 交互设计稿，生产页面继续使用现有 HTML/CSS/JavaScript 和 FastAPI 接口。

## 视觉方向

- 浅灰画布与深石墨导航区形成空间层次，冷蓝色用于主要操作、当前导航与模型状态。
- 左侧主画布优先展示检测结果，右侧配置区域承载上传、场景、阈值与鉴权。
- 预览区采用独立深色画布，完整显示标注图；顶部显示文件名，底部显示真实任务状态。
- 指标采用等宽数字与独立卡片，分类统计和导出操作位于同一区域。
- 图标使用项目内 SVG，空态采用 CSS 几何图形；中文 UI 使用随项目分发的 Noto Sans SC 字符子集，无运行时外部字体或图片 CDN 依赖。
- 小屏幕将上传配置前置，再显示预览与分析；表格在自己的容器内横向滚动。
- 提供可见键盘焦点、减少动画偏好支持和状态颜色之外的文字说明。

## 交互边界

MagicPath 画布为设计预览：可选择输入、调整阈值、查看官方示例画面；不会伪造模型检测数据。实际工作台中的“体验示例”会上传随项目分发的官方样图并运行真实 YOLO 检测。数据卡片与历史仅显示接口返回值。
